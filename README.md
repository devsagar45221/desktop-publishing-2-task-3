# desktop-publishing-2-task-3
Create a Creative Travel Poster in Photoshop
1. Open Adobe Photoshop and create a new A4 document.
2. Import at least three travel photographs using File → Place Embedded.
3. Place each photograph on a separate layer.
4. Rename the layers appropriately, such as Mountain, Lake, Forest, and Background.
5. Use the Move Tool (V) to adjust image positions.
6. Press Ctrl + T to resize, rotate, or transform images.
7. Add a suitable background using a solid color or gradient.
8. Select an image layer and click Add Layer Mask.
9. Use the Brush Tool (B) with black and white to hide or reveal image portions.
10. Use a soft brush or Gradient Tool to blend photographs.
11. Select the Type Tool (T) and add a suitable title and supporting text.
12. Double-click the title layer to open Layer Style.
13. Apply a Drop Shadow, Stroke, or Outer Glow effect.
14. Adjust colors, alignment, and spacing to improve the composition.
15. Save the project as Travel_Poster.psd using File → Save As.
16. Export the final composition using File → Export → Export As in JPEG or PNG format.
Practical 2: Photo Editing Using Selection Tools and Adjustment Layers
1. Open Adobe Photoshop and import a photograph using File → Open.
2. Duplicate the original layer using Ctrl + J.
3. Rename the layers Original and Edited Subject.
4. Select the main subject using the Quick Selection Tool, Magic Wand Tool, or Lasso Tool.
5. Click Select → Select and Mask to refine the selection edges.
6. Adjust Smooth, Feather, Contrast, and Shift Edge as required.
7. Create a Brightness/Contrast Adjustment Layer using Layer → New Adjustment Layer → Brightness/Contrast.
8. Adjust brightness and contrast to improve the subject's appearance.
9. Create a second Hue/Saturation Adjustment Layer.
10. Adjust Hue, Saturation, and Lightness to modify colors.
11. Use the adjustment layer masks to control where the effects appear.
12. Paint with black on a mask to hide an adjustment and white to reveal it.
13. Keep the original photograph unchanged.
14. Arrange the original and edited photographs side by side using the Move Tool (V).
15. Add BEFORE and AFTER labels using the Type Tool (T).
16. Save the project as Photo_Editing.psd.
17. Export the final composition as a JPEG or PNG using File → Export → Export As.
